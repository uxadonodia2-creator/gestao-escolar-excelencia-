# 🎓 Vitrine — Gestão Escolar de Excelência

## Pós-Graduação em Gestão Escolar de Excelência

Vitrine digital profissional desenvolvida para apresentar e divulgar a **Pós-Graduação em Gestão Escolar de Excelência**.

O projeto foi desenvolvido com foco em uma experiência moderna, organizada, responsiva e adaptada para diferentes dispositivos.

---

## 📚 Sobre o projeto

A página apresenta informações sobre a formação, seus principais diferenciais, público-alvo, grade curricular e orientações para matrícula.

O objetivo da vitrine é facilitar a compreensão do curso e direcionar o visitante para a página de matrícula e pagamento.

---

## 📱 Design Responsivo

O site utiliza **Responsive Web Design**, permitindo que a interface se adapte automaticamente a diferentes tamanhos de tela.

O projeto foi desenvolvido para funcionar em:

- 📱 Celulares
- 📲 Tablets
- 💻 Notebooks
- 🖥️ Computadores

A mesma página é utilizada em todos os dispositivos, com o layout se reorganizando de acordo com o tamanho da tela.

---

## 🛠️ Tecnologias utilizadas

### HTML5
Responsável pela estrutura e organização do conteúdo da página.

### CSS3
Responsável pelo design visual, layout, animações, responsividade e adaptação para diferentes tamanhos de tela.

### JavaScript
Responsável pelas interações e funcionalidades da página, como menu mobile, navegação e efeitos de interface.

### Google Fonts
Utilizado para melhorar a apresentação tipográfica do projeto.

### GitHub Pages
Utilizado para hospedagem e publicação do site.
